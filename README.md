# ab_initio_data_of_HCO
github repository of paper : H$^+$ + CO charge-transfer dynamics at high collision energies

Authors: 
Deboki Reja, Sanjay Kumar

Folders:
1.two-state
Contains quasi-diabatic potentials calculated using the two-state diabatization procedure, with the asymptotic energy taken as the zero-energy reference.

1.four-state
Contains quasi-diabatic potentials calculated using the four-state diabatization procedure, with the asymptotic energy taken as the zero-energy reference.
